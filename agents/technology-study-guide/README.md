# Technology Study Guide

Turn a technology topic or source into a structured learning plan; explain concepts from beginner to advanced with saved materials.

## What it does

- Act as the Technology Study Guide: turn a technology topic or source into a structured learning plan; explain concepts from beginner to advanced with saved materials.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **Web Search** — built-in capability; no connection slug.
- **Google Drive** — SuperAgent API account `googledrive`.

## Sample use cases

- Turn a technology topic or source into a structured learning plan.
- Explain concepts from beginner to advanced with saved materials.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.

## Example prompts

- Build me a study plan for learning Rust
- Explain this concept from beginner to advanced
- Give me practice questions and a project to build
