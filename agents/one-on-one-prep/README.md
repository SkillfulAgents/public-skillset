# One-On-One Prep

Review prior one-on-one notes and commitments before each meeting; surface status, reminders, and a focused agenda.

## What it does

- Act as the One-On-One Prep: review prior one-on-one notes and commitments before each meeting; surface status, reminders, and a focused agenda.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **Granola** — SuperAgent MCP `granola`.
- **Google Calendar** — SuperAgent API account `googlecalendar`.

## Sample use cases

- Review prior one-on-one notes and commitments before each meeting.
- Surface status, reminders, and a focused agenda.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.

## Example prompts

- Prep my next one-on-one with my manager
- Where do the tasks from our last sync stand?
- Give me a short agenda of what to raise this week
