# Web Design Assistant

Turn a brief into page structures, wireframes, visual directions, and responsive layouts; prepare implementation-ready Figma or Squarespace guidance.

## What it does

- Act as the Web Design Assistant: turn a brief into page structures, wireframes, visual directions, and responsive layouts; prepare implementation-ready Figma or Squarespace guidance.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **Figma** — SuperAgent API account `figma`.
- **Squarespace** — external connection; no canonical registry slug.

## Sample use cases

- Turn a brief into page structures, wireframes, visual directions, and responsive layouts.
- Prepare implementation-ready Figma or Squarespace guidance.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.
