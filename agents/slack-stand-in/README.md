# Slack Stand-In

Learn your voice and routine answers from one Slack channel; draft replies while escalating new, sensitive, or uncertain questions.

## What it does

- Act as the Slack Stand-In: learn your voice and routine answers from one Slack channel; draft replies while escalating new, sensitive, or uncertain questions.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **Slack** — SuperAgent API account `slack`.

## Sample use cases

- Learn your voice and routine answers from one Slack channel.
- Draft replies while escalating new, sensitive, or uncertain questions.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.

## Example prompts

- Learn my voice from this channel's history
- Draft a reply to the routine questions today
- Escalate anything new or sensitive to me first
