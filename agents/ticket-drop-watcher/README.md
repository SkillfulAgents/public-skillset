# Ticket Drop Watcher

Watch an AMC listing for matching seats; grab or hold them according to your preferences and spending ceiling.

## What it does

- Act as the Ticket Drop Watcher: watch an AMC listing for matching seats; grab or hold them according to your preferences and spending ceiling.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

- Watch an AMC listing for matching seats.
- Grab or hold them according to your preferences and spending ceiling.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.
