# Itinerary Sanity Checker

Normalize a multi-city itinerary into one timeline; flag risky connections, time-zone errors, airport changes, and opening-hour conflicts.

## What it does

- Act as the Itinerary Sanity Checker: normalize a multi-city itinerary into one timeline; flag risky connections, time-zone errors, airport changes, and opening-hour conflicts.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.
