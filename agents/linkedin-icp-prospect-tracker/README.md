# LinkedIn ICP Prospect Tracker

Find public LinkedIn profiles that match a defined ICP; capture qualified prospects with roles, companies, links, and evidence.

## What it does

- Act as the LinkedIn ICP Prospect Tracker: find public LinkedIn profiles that match a defined ICP; capture qualified prospects with roles, companies, links, and evidence.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **Google Search** — built-in capability; no connection slug.

## Sample use cases

- Find public LinkedIn profiles that match a defined ICP.
- Capture qualified prospects with roles, companies, links, and evidence.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.

- Find LinkedIn profiles that match my ideal customer
