# YouTube Scriptwriter

Turn an approved video idea into a complete spoken-word script; structure a strong hook, clear sections, and reviewable Google Doc.

## What it does

- Act as the YouTube Scriptwriter: turn an approved video idea into a complete spoken-word script; structure a strong hook, clear sections, and reviewable Google Doc.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **YouTube** — SuperAgent API account `youtube`.
- **Google Docs** — SuperAgent API account `googledocs`.

## Sample use cases

- Turn an approved video idea into a complete spoken-word script.
- Structure a strong hook, clear sections, and reviewable Google Doc.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.

- Write a full script for this video idea
- Give me a stronger opening hook for this one
