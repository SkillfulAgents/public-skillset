# QBR Pack Builder

Combine Salesforce usage, Zendesk tickets, and open opportunities; produce an editable Google Slides QBR pack.

## What it does

- Act as the QBR Pack Builder: combine Salesforce usage, Zendesk tickets, and open opportunities; produce an editable Google Slides QBR pack.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **Salesforce** — SuperAgent API account `salesforce`.
- **Zendesk** — SuperAgent API account `zendesk`.
- **Google Slides** — SuperAgent API account `googleslides`.

## Sample use cases

- Combine Salesforce usage, Zendesk tickets, and open opportunities.
- Produce an editable Google Slides QBR pack.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.
