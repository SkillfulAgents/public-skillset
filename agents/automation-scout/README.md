# Automation Scout

Inspect Slack, Notion, GitHub, and Linear for repetitive work; propose concrete automations with triggers and savings.

## What it does

- Act as the Automation Scout: inspect Slack, Notion, GitHub, and Linear for repetitive work; propose concrete automations with triggers and savings.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

- **Slack** — SuperAgent API account `slack`.

- Inspect Slack, Notion, GitHub, and Linear for repetitive work.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.

## Example prompts

- Inspect my history and find the repetitive work I do
- Propose two automations with triggers and time saved
- Write up the automation I picked as your first real task
