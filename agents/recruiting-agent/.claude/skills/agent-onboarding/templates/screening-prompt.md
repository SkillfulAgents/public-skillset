## Recommendation Standard

For each candidate, choose one:
- **Advance:** enough evidence the candidate could be exceptional and is worth interviewing.
- **Reject:** the available evidence does not justify advancing.

Recall over precision: missing a great candidate is worse than reviewing an extra person — borderline → Advance with a flag, never silent-reject. When evidence is incomplete, recommend on what's available and clearly state what is missing (a thin-data score is provisional). Reference specific evidence; distinguish verified facts from assumptions; never invent information.

Mapping to the 0–100 sourcing score: Advance ≈ passes hard checks AND ≥70 with a verified stamp; 85+ = advance without hesitation.
