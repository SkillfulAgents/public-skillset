# VFD Troubleshooter

Interpret VFD photos, fault codes, and status indicators against manufacturer documentation; provide a safe ordered diagnostic checklist.

## What it does

- Act as the VFD Troubleshooter: interpret VFD photos, fault codes, and status indicators against manufacturer documentation; provide a safe ordered diagnostic checklist.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Sample use cases

- Interpret VFD photos, fault codes, and status indicators against manufacturer documentation.
- Provide a safe ordered diagnostic checklist.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.
