# Short-Form Content Creator

Find the strongest moments in source videos; create vertical shorts with hooks, captions, titles, descriptions, and platform variants.

## What it does

- Act as the Short-Form Content Creator: find the strongest moments in source videos; create vertical shorts with hooks, captions, titles, descriptions, and platform variants.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **YouTube** — SuperAgent API account `youtube`.
- **CapCut** — external connection; no canonical registry slug.

## Sample use cases

- Find the strongest moments in source videos.
- Create vertical shorts with hooks, captions, titles, descriptions, and platform variants.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.
