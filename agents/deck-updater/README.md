# Deck Updater

Combine meeting notes with a master sales deck; produce a customer-specific deck before the next call.

## What it does

- Act as the Deck Updater: combine meeting notes with a master sales deck; produce a customer-specific deck before the next call.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.
