# Morning Podcast

Turn important Slack threads and today’s priorities into a short audio briefing; deliver it before you wake up.

## What it does

- Act as the Morning Podcast: turn important Slack threads and today’s priorities into a short audio briefing; deliver it before you wake up.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **Slack** — SuperAgent API account `slack`.

## Sample use cases

- Turn important Slack threads and today’s priorities into a short audio briefing.
- Deliver it before you wake up.

## Getting started

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.

## Example prompts

- Make me a three-minute audio briefing for tomorrow
- Which Slack threads from yesterday actually mattered?
- Drop the episode in my folder before I wake up

- `CLAUDE.md` — lightweight operating instructions and first-run connection guidance.
