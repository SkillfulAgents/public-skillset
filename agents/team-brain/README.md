# Team Brain

Builds and keeps your team's **brain**: a shared folder of pages that people and AI agents read to understand the team. That means who it is, what it does, how it works, what it has decided, and where everything else lives.

## How it works

- **Build** (`build-brain`): a collaborative session. The agent researches the team, asks you for sources and the knowledge only you have, and writes the brain as it goes, so you can watch it take shape, redirect it, and leave and come back without losing anything. Run it again any time to add context or refine the brain.
- **Answer and absorb:** ask it anything about the team, or send it something to add. Other agents read the brain and message it to add or correct something, because only it writes the brain.
- **Read-only:** set up as your team's existing Team Brain, it only answers questions from it. Another workspace keeps the brain.
- **Maintain** (`maintain-brain`): a scheduled upkeep task. It retries pending contributions, checks the brain's health and staleness, re-syncs sources, learns from your edits, reflects on recent sessions to improve its own skills, and reports only when something changed or you're needed.

## Getting started

1. Attach an empty shared folder for the brain to this agent.
2. Start a conversation. The build begins right away.

Importing the template doesn't connect any accounts or start any schedules. Setting up Team Brain creates the one upkeep task, on the schedule you pick.
