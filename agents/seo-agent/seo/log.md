# SEO Run Log

> Append-only. Every scheduled run (daily content, daily links, weekly strategy,
> technical audit) appends a dated entry: what shipped, URLs, counts, failures.
> The dashboard's Program section parses this file.

Entry format:

```
## YYYY-MM-DD (daily content)
- [article] "Title here" — primary kw "..." — PUBLISHED https://...
```
