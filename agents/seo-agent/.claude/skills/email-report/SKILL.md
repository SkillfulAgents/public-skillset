# Email Report

Turns a markdown report file into a formatted HTML email and sends it through the Gmail
proxy. Replaces pasting raw markdown into the body — tables become real tables, headings
get hierarchy, and the raw markdown still goes out as the `text/plain` alternative.

Sender identity, default recipient, and header brand come from `/workspace/seo/config.json`
(`report.from_email`, `report.gmail_account_id`, `report.to`, `report.brand`) — written by
the `agent-onboarding` skill.

## Usage

Preview (writes HTML, sends nothing):

```bash
uv run --env-file .env --with markdown,requests \
  .claude/skills/email-report/send_report.py \
  --md reports/seo-weekly-2026-08-10.md \
  --preview /tmp/weekly.html
```

Send:

```bash
uv run --env-file .env --with markdown,requests \
  .claude/skills/email-report/send_report.py \
  --md reports/seo-weekly-2026-08-10.md \
  --subject 'SEO weekly — 2026-08-10' \
  --preheader 'Non-brand clicks tripled; DR flat — links still the bottleneck' \
  --summary-md /tmp/highlights.md
```

## Options

| Flag | Purpose |
|---|---|
| `--md` | Markdown report file (required) |
| `--to`, `--subject` | `--to` defaults to `report.to` from config; `--subject` required unless `--preview` |
| `--from`, `--account-id` | Default to `report.from_email` / `report.gmail_account_id` from config |
| `--title` | Header title; defaults to the report's leading `#` H1 (which is then dropped from the body so it isn't repeated) |
| `--summary` / `--summary-md` | Markdown for the "Highlights" box above the report — inline text or a file |
| `--preheader` | Inbox preview snippet (hidden in the body) |
| `--footer` | Footer line; defaults to a "generated by the SEO agent" + report path note |
| `--preview` | Write HTML to this path instead of sending |

## Rendering notes

- All CSS is **inlined per tag** (`render.py:TAG_STYLES`) because Gmail strips `<style>`
  blocks in several clients; layout is table-based for the same reason.
- Table cells whose value starts with `+`/`-` followed by a digit or `$` are tinted green /
  red so week-over-week movement reads at a glance. `flat` and `—` stay neutral.
- Supported markdown: headings, tables, lists, bold/italic, links, inline code, fenced
  code, blockquotes, hr. Images are not styled for email — keep reports text+table only.
- Reports commonly put a bold lead-in (`**Articles (Mon–Thu):**`) directly above a table
  or bullet list with no blank line; markdown needs that blank line or the block collapses
  into one paragraph (a table degrades to raw `|---|` pipes). `_blank_line_before_blocks`
  inserts it, so reports don't have to be written defensively.
- Reports only. **Outreach/pitch emails stay plain text** — templated HTML hurts reply
  rates and deliverability.
