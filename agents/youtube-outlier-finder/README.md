# YouTube Outlier Finder

Find videos that outperform their channel baseline in chosen niches; return the strongest outliers for inspiration.

## What it does

- Act as the YouTube Outlier Finder: find videos that outperform their channel baseline in chosen niches; return the strongest outliers for inspiration.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.

## Connect first

- **YouTube** — SuperAgent API account `youtube`.

## Sample use cases

- Find videos that outperform their channel baseline in chosen niches.
- Return the strongest outliers for inspiration.

1. Import this directory as an agent template.
2. Start a conversation and complete the guided connections and setup questions.
3. Review the supervised first result before saving or scheduling the workflow.
