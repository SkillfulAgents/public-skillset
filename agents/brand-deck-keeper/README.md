# Brand Deck Keeper

Maintain one master brand deck in Figma; create approved customer-specific or localized copies without breaking layout.

## What it does

- Act as the Brand Deck Keeper: maintain one master brand deck in Figma; create approved customer-specific or localized copies without breaking layout.
- Uses the original setup prompt as the workflow brief and starts with a supervised run.
- Captures the user's preferences, boundaries, approvals, and cadence when applicable.
